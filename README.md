# Snow Day Prediction Model

This Python script simulates a simplified snow day prediction system. It uses temperature and snowfall data against predefined thresholds to forecast if schools might close, mimicking the core logic of the SnowDayCA project.

## Language

`python`

## How to Run

Save the code as `snow_day_predictor.py` and run it from your terminal using `python snow_day_predictor.py`.
